# Сервис синхронизации файлов с Яндекс Диском

Программа следит за папкой на компьютере и поддерживает её копию в папке на Яндекс Диске:

- новый файл загружается на Диск;
- изменённый файл перезаписывается на Диске;
- удалённый файл удаляется с Диска.

При запуске папка на Диске сразу приводится в соответствие с локальной, дальше проверка повторяется с заданным периодом. Вложенные папки не синхронизируются. Ошибки сети и чтения файлов записываются в лог и не останавливают программу.

## Установка

Нужен Python 3.11 или новее.

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Настройка

1. Получите OAuth-токен на [Полигоне Яндекс Диска](https://yandex.ru/dev/disk/poligon/).
2. Создайте на Яндекс Диске папку для резервных копий.
3. Скопируйте `.env.example` в `.env` и заполните параметры:

| Параметр | Что указать |
|---|---|
| `LOCAL_FOLDER` | путь к локальной папке |
| `CLOUD_FOLDER` | папка на Яндекс Диске |
| `TOKEN` | OAuth-токен |
| `SYNC_PERIOD` | период синхронизации в секундах |
| `LOG_FILE` | путь к файлу лога |

## Запуск

```
python main.py
```

Остановить программу: `Ctrl+C`.

## Структура

- `main.py` — настройка программы и цикл синхронизации.
- `yandex_disk.py` — класс `YandexDisk` для работы с API Яндекс Диска: `load`, `reload`, `delete`, `get_info`. Чтобы подключить другое хранилище, достаточно написать класс с такими же методами.
